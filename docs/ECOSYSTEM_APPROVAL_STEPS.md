# Ecosystem Wallet Approval — Action Required

**One-time setup** needed before agents can receive their 1,000 SMESH enrollment reward.

## What & Why

The new AgentRegistry v2 pulls 1,000 SMESH from the ecosystem wallet directly to each newly registered agent. For this to work, the ecosystem wallet must pre-approve the registry contract to spend SMESH on its behalf.

| | |
|---|---|
| **Ecosystem wallet** | `0x280d5A5C052AD64C4f72f58f694C33beD29E175E` |
| **AgentRegistry v2** | `0x55684533a539eC77099A13ceD3C0B8665Cd0302b` |
| **SMESH Token** | `0xDA31b578841d6d4417Dba55EFbdbF068e101a67a` |
| **Approve amount** | 300,000,000 SMESH (300M — the full ecosystem allocation) |
| **Amount in wei** | `300000000000000000000000000` |

## Step-by-Step Instructions

### Option A — Via Basescan (Recommended)

1. Open [Basescan SMESH Token Write Contract](https://basescan.org/address/0xDA31b578841d6d4417Dba55EFbdbF068e101a67a#writeContract)

2. Click **"Connect to Web3"** and connect MetaMask

3. Make sure MetaMask is using the **ecosystem wallet**:
   ```
   0x280d5A5C052AD64C4f72f58f694C33beD29E175E
   ```
   (Switch to it in MetaMask if needed)

4. Find the **`approve`** function and expand it

5. Fill in:
   - **`spender (address)`**: `0x55684533a539eC77099A13ceD3C0B8665Cd0302b`
   - **`amount (uint256)`**: `300000000000000000000000000`

6. Click **Write** and confirm the transaction in MetaMask

7. Wait for confirmation (usually ~2–5 seconds on Base)

Done! The registry can now send 1,000 SMESH rewards to enrolling agents.

---

### Option B — Via MetaMask + Contract Interaction

1. In MetaMask, switch to the ecosystem wallet on **Base Mainnet**

2. Go to the SMESH token contract: `0xDA31b578841d6d4417Dba55EFbdbF068e101a67a`

3. Call `approve(spender, amount)`:
   ```
   spender: 0x55684533a539eC77099A13ceD3C0B8665Cd0302b
   amount:  300000000000000000000000000
   ```
